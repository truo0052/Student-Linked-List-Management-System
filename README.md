# Student Linked List Management System

A simple C program that implements a linked list to manage student records.

## Description

This program demonstrates basic linked list operations in C. It stores student names (first and last) and allows adding, deleting, and displaying students in the list.

## Features

- Add students to front or back of list
- Delete students from front, back, or specific positions
- Display all students
- Proper memory management

## Usage

The program will prompt you to enter student names and then demonstrate various list operations:
- Adds 3 students to the front
- Adds 3 students to the back
- Displays and deletes students in different ways
